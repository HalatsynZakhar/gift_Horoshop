Подарунки Хорошоп

Масове та ручне керування подарунками товарів і їхніх варіацій.

Готово до роботи

Доступ до API

Для кожної операції потрібні логін і пароль API або чинний токен. Дані не зберігаються у браузері.

Додати подарунок вручну

Вказуйте артикул зі сайту, внутрішній артикул Хорошоп або артикул із бази сопоставлень. Якщо артикул розкривається у кілька варіацій, усі знайдені варіації подарунка призначаються всім знайденим варіаціям основного товару.

Масові операції через Excel

Завантажити базу (Excel)
Перетягніть Excel-файл подарунків сюди або натисніть для вибору Підтримуються .xlsx та .xlsm. Два стовпці: артикул основного товару та артикул подарунка (плюс необов'язковий «Видалити (Так)»).
Завантажити шаблон

Для масового видалення спочатку вивантажте поточні подарунки нижче, позначте потрібні рядки «Так» у стовпці «Видалити (Так)» і завантажте цей файл сюди.

1
Заповніть шаблон

Кожен рядок додає зв'язок між основним товаром і подарунком з автоматичним розкриттям варіацій із бази сопоставлень.

2
Перевірте файл

Статус «Готово до операції» означає, що рядок можна передати в Хорошоп.

3
Виконайте операції

Поточні подарунки товару не стираються, змінюються тільки зазначені зв'язки.

Результат останньої операції

Після перевірки виправте лише рядки зі статусом «Помилка», а рядки «Готово до операції» можна запускати.

Ще немає результатів.
