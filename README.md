# Подарунки Хорошоп

Веб-сервіс призначає подарунки товарам через API Хорошоп. У полях форми та Excel можна вказувати `article_for_display` (артикул, що відображається на сайті), внутрішній `article` Хорошоп або артикул із бази сопоставлень (постачальника, груповий артикул чи модифікацію). Сервіс знаходить відповідні внутрішні `article` в експорті каталогу та передає їх Хорошопу.

## Запуск

1. У `config.json` вкажіть домен магазину, логін/пароль до API Хорошоп та реквізити входу в сервіс. За замовчуванням сервіс використовує порт `8094`.
2. Встановіть залежності: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
3. Запустіть `.\.venv\Scripts\python.exe gifts_server.py`.
4. Відкрийте `http://<сервер>:8094`.

Для входу в веб-панель за замовчуванням встановлено логін `admin` і пароль `Bublik44` (налаштовується у секції `auth` та `admin_password` файлу `config.json`). Логін і пароль до API Хорошоп зберігаються у `config.json` і завантажуються автоматично, тому поля у веб-панелі можна не заповнювати щоразу вручну.

## Як працюють подарунки та розкриття варіацій

API Хорошоп перезаписує весь масив `gifts` основного товару. Тому перед кожною операцією сервіс експортує каталог, зберігає вже призначені подарунки та:

- при додаванні дописує лише новий подарунок;
- при видаленні прибирає лише обраний подарунок;
- показує поточні зв'язки безпосередньо з експорту Хорошоп;
- **розкриває варіації через базу сопоставлень** як для основного товару, так і для подарунка: якщо за основним артикулом та/або артикулом подарунка у базі сопоставлень закріплено декілька варіацій (подартикулів/модифікацій), усі знайдені варіації подарунка автоматично призначаються (або видаляються) всім знайденим варіаціям основного товару (як при ручному додаванні, так і при масовому імпорті з Excel).

Подарунки, призначені раніше вручну або іншим сервісом, не стираються.

## База сопоставлень (відповідностей) артикулів

Сервіс підтримує завантаження та збереження зв'язків між артикулами постачальників/файлів, груповими артикулами, модифікаціями та артикулами каталогу Хорошоп (`data/article_mappings.json`):

- **Суворий облік початкових нулів**: `04040` і `4040`, `04055` і `4055` є принципово різними артикулами та різними товарами. Пошук і нормалізація суворо розрізняють кількість початкових нулів — артикул `4040` ніколи не зіставиться з `04040` і навпаки.
- **Фільтрація некорисних рядків**: під час завантаження таблиці сопоставлень рядки без корисної інформації (одиночні артикули без пари, дубльовані однакові значення або збіги без урахування регістру) автоматично відсіюються і не засмічують базу.
- **Захист від некоректних зв'язків**: якщо в одному рядку файлу сопоставлень передані артикули, що відрізняються лише початковими нулями (наприклад, `04040` і `4040`), сервіс перериває завантаження зі зрозумілою помилкою для запобігання псуванню бази.
- **Перегляд і експорт в Excel**: кнопка **«Завантажити базу (Excel)»** (`/api/mappings/export`) вивантажує поточні відповідності у файл `.xlsx` із двома вкладками: компактні групи артикулів (готові для повторного завантаження) та повний алфавітний реєстр пошуку. Усі артикули зберігаються суворо в текстовому форматі `@`, що гарантує збереження початкових нулів.
- **Видалення даних бази**: кнопка **«Видалити дані бази»** (`/api/mappings/clear`) очищує базу, попередньо створюючи резервну копію зі штампом часу (наприклад, `article_mappings_20261030_021500.json.bak`).

## Excel та звіти

Шаблон містить дві колонки:

| Колонка | Значення |
| --- | --- |
| Артикул основного товару | `article_for_display`, внутрішній `article` або артикул із бази сопоставлень товару, до якого додається подарунок. |
| Артикул подарунка | `article_for_display`, внутрішній `article` або артикул із бази сопоставлень товару-подарунка. |

Вивантаження поточних подарунків містить додаткову колонку `Видалити (Так)`. Впишіть `Так` навпроти зв'язків, які треба видалити, і завантажте файл назад. Порожня клітинка означає додавання або збереження зв'язку.

Пошук артикулів виконується спочатку точним збігом, потім без урахування регістру, а за увімкненої опції **«Нормалізувати артикул, якщо його не знайдено»** — також із нормалізацією роздільників та суворим збереженням початкових нулів.

Після перевірки Excel, виконання масового імпорту або ручного додавання доступні:
- **«Завантажити детальний звіт»** (`horoshop_gifts_report.xlsx` / `horoshop_gifts_preview.xlsx`) — містить вхідні артикули, артикули сайту, внутрішні артикули Хорошоп, перелік подарунків до і після операції, статус та примітки.
- **«Завантажити Excel з помилками»** (`horoshop_gifts_failed.xlsx`) — містить усі рядки, які не пройшли перевірку або імпорт, із зазначенням причини помилки.

## Візуальне відображення та XML-фід зображень

Сервіс інтегрований з XML-фідом фотографій товарів (`http://176.104.6.149:8080/xml/images_export.xml`, параметр `"images_xml_url"` у `config.json`):

- **Кешування та фонове завантаження**: фід автоматично кешується локально у `data/cache/images_export.xml` і перевіряється раз на 4 години або за потреби підтягується із сусідніх проектів на сервері.
- **Мініатюри та інформація про бренд**: у таблицях результатів та реєстрі поточних подарунків кожен товар і подарунок відображаються у вигляді зручних карток із фотографією, брендом та артикулом.
- **Швидкий перемикач «🖼️ Показувати фото»**: одним кліком можна увімкнути або вимкнути зображення (стан зберігається у браузері).
- **Збільшення фото (Lightbox)**: клік на будь-яку мініатюру відкриває модальне вікно з великим фото високої якості, назвою бренду, артикулом та прямим посиланням на зображення.
- **Інтерактивний Live Preview**: під час ручного додавання подарунка при введенні артикулів основного товару та подарунка одразу показується живий візуальний попередній перегляд зв'язку товарів із фотографіями.
- **Пошук у реєстрі**: поле швидкого пошуку дозволяє миттєво відфільтрувати зв'язки за артикулом або брендом основного товару чи подарунка.

## Публічний лог

У `config.json` вкажіть папку, яка доступна для перегляду, та спільний файл:

```json
"logging": {
  "public_log_path": "C:/ShareFiles/public",
  "public_log_name": "horoshop_gifts.log"
}
```

У цей файл записуються повідомлення контролера оновлень, Uvicorn, API та помилки. У JSON використовуйте прямі слеші `/` або подвійні зворотні `\\`.

## Windows Server

Запускайте PowerShell від імені адміністратора:

```powershell
.\FULL_SERVER_INSTALL.ps1
```

Інсталятор створює `config.json`, зупиняє попередню версію, виконує `git reset --hard` та запускає контролер автооновлення. Контролер перевіряє Git кожні п'ять хвилин, не створює середовище заново та повертає попередню версію, якщо оновлення не пройшло перевірку.

Для повної зупинки:

```powershell
.\scripts\stop_tasks.ps1
```
